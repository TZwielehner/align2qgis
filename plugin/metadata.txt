[general]
name=Align2QGIS
qgisMinimumVersion=3.22
description=Import LandXML horizontal alignments (lines, arcs, clothoid spirals) as QGIS line geometry.
about=Reads LandXML Alignment/CoordGeom elements and produces a memory line layer with one feature per alignment. Spirals are discretized via Fresnel integration; arcs use exact circular arc math; lines are straight segments. Coordinate order follows the LandXML standard (Northing Easting); the plugin emits QGIS (X=Easting, Y=Northing).
